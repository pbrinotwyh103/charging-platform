# 充电运营分析大屏设计系统

> 适用范围：仅 `bigdata/dashboard` 中由 Flask 托管的 Vue 3 + ECharts Web 分析大屏。
> 状态：设计基线；尚未实施。
> 设计依据：UI/UX Pro Max 的 `Data-Dense Dashboard`、`Drill-Down Analytics`、`Minimalism & Swiss Style` 建议，并采用 `Smart Home / IoT Dashboard` 深色配色模板。

## 1. 设计原则

1. **分析优先**：视线首先落在异常、趋势和可操作结论，不落在装饰。
2. **密而不挤**：桌面端最大化有效信息量；依靠清晰分组、对齐和节奏保持可读性。
3. **状态可信**：更新时间、数据新鲜度、加载、空、错误、降级状态始终明确。
4. **交互可追溯**：筛选条件、选中对象、钻取层级和返回路径均可见。
5. **身份延续**：保留深色基底、青色主强调和蓝色数据色；不替换 Vue 3 或 ECharts。
6. **克制表达**：减少大面积渐变、重阴影、超大 KPI 和无意义动画。

设计旋钮：视觉差异度 `3/10`、动效 `2/10`、信息密度 `9/10`。

## 2. 设计令牌

### 2.1 色彩

所有业务组件只使用语义令牌，不直接写十六进制色值。

| 语义 | 建议值 | 用途 |
|---|---:|---|
| `--color-bg-canvas` | `#0F172A` | 页面底色 |
| `--color-bg-surface` | `#1B2336` | 面板、表格底色 |
| `--color-bg-elevated` | `#272F42` | 浮层、悬停、选中区域 |
| `--color-bg-subtle` | `#111827` | 次级分区 |
| `--color-text-primary` | `#F8FAFC` | 标题、关键数字 |
| `--color-text-secondary` | `#CBD5E1` | 正文、图例 |
| `--color-text-muted` | `#94A3B8` | 辅助信息 |
| `--color-border` | `#475569` | 常规边框 |
| `--color-border-strong` | `#64748B` | 强分隔、悬停 |
| `--color-primary` | `#22C55E` | 当前视图、在线状态、主交互 |
| `--color-primary-subtle` | `#16351F` | 主色低强调背景 |
| `--color-info` | `#3B82F6` | 信息、对照序列 |
| `--color-success` | `#22C55E` | 正常、提升 |
| `--color-warning` | `#F59E0B` | 关注、容量预警 |
| `--color-danger` | `#EF4444` | 故障、下降、严重告警 |
| `--color-violet` | `#8B5CF6` | 第五分类序列 |
| `--color-focus` | `#86EFAC` | 键盘焦点环 |

约束：

- 正文对背景对比度至少 `4.5:1`，大字至少 `3:1`。
- 状态不可只靠颜色表达；同时使用文字、图标、线型或纹理。
- 主色用于选择与关键行为，不把整块面板染成主色。
- 渐变只允许表达连续数值（如热力、置信区间）；禁止作为常规卡片装饰。

### 2.2 图表序列色

固定顺序：天蓝 `#38BDF8`、蓝 `#3B82F6`、绿 `#22C55E`、橙 `#F59E0B`、红 `#EF4444`、紫 `#8B5CF6`。同一指标跨页面保持同色。实际值使用实线，预测值使用虚线，置信区间使用同色 12%–18% 透明带。

### 2.3 字体与数字

使用本机字体栈，不引入网络字体：

```css
font-family: "PingFang SC", "Microsoft YaHei", "Noto Sans CJK SC", "Segoe UI", sans-serif;
```

| 层级 | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| Display | `28/36` | 700 | 页面核心总量，限一处 |
| H1 | `24/32` | 700 | 页面标题 |
| H2 | `18/26` | 600 | 面板标题 |
| H3 | `16/24` | 600 | 分组标题 |
| Body | `14/22` | 400 | 正文、表格 |
| Small | `13/20` | 400/500 | 控件、图例 |
| Caption | `12/18` | 400 | 单位、时间、来源 |

数字统一使用 `font-variant-numeric: tabular-nums`；金额、百分比、功率与计数不得混用格式。单位放在数值或轴标题旁，不藏在提示框中。

### 2.4 间距、尺寸与布局

- 基础间距：`4, 8, 12, 16, 20, 24, 32px`。
- 页面外边距：`24px`（≥1440），`20px`（1200–1439），`16px`（960–1199），`12px`（<960）。
- 网格：12 列；常规间隙 `12px`，高密区 `8px`。
- 顶栏：`56px`；筛选工具栏：`44px`；默认控件：`36px`，紧凑控件：`32px`。
- 表格行高：默认 `40px`，紧凑 `36px`；表头 `40px`。
- 面板内边距：`16px`；紧凑数据面板 `12px`。
- 圆角：控件 `6px`，面板 `8px`，浮层 `10px`；仅状态徽标使用胶囊形。
- 阴影：普通面板无阴影，以边框分层；浮层使用 `0 8px 24px rgba(0,0,0,.28)`。

### 2.5 动效与层级

- 状态过渡 `120ms`，面板/浮层 `180ms`，视图切换最多 `240ms`。
- 仅使用透明度和轻微颜色变化；禁止滚动入场、漂浮、循环脉冲和大幅位移。
- 支持 `prefers-reduced-motion: reduce`。
- 层级：基础 `0`、粘性表头 `10`、顶栏 `20`、下拉 `40`、弹层 `60`、通知 `80`。

## 3. 布局与导航规则

- 顶栏分成品牌/当前页面、数据更新时间与健康状态、全局操作三组。
- 保留现有“运营 / 监管 / 租户”视图语义和状态切换；呈现为紧凑、可键盘操作的标签组。
- 标签使用 `role=tablist/tab/panel` 和 `aria-selected`，左右方向键可切换。
- 页面采用“顶栏 → 视图导航 → 筛选/上下文条 → 内容”的固定层次。
- ≥1440 为三列分析网格；1200–1439 为两列；960–1199 为两列但大图跨列；<960 单列。不得通过缩小文字维持三列。
- 视图切换、筛选和刷新不得改变后端接口或 URL/路由语义。

## 4. 组件规则

### 状态条

加载、错误、空数据、数据过期分别使用固定语义色和图标；错误必须提供重试，过期必须展示最后成功更新时间。状态条不得推挤关键内容产生大幅跳动。

### KPI 指标带

- 用单行/双行紧凑指标带替代六个大型卡片。
- 每项包含标签、主值、单位、环比/同比、更新时间或口径提示。
- 主值建议 `24–28px`，单项最小宽度 `160px`；不使用插图、渐变或阴影。
- 可点击项必须有明确的悬停、焦点和钻取指示；不可点击项不伪装成按钮。

### 面板与图表面板

- 标题栏顺序：标题、口径/单位、可选上下文、操作。
- 图表绘图区优先，标题区不超过 `44px`。
- 单个面板只回答一个分析问题；有关联的图表与表格使用共享筛选上下文。
- 工程标签、表名和调试信息移入“数据口径”提示，不直接占据业务标题。

### 筛选与钻取

- 高频条件常驻筛选条，低频条件收纳为“更多筛选”。
- 立即生效的轻量条件和“应用”式重查询不可混用；页面统一一种反馈模式。
- 激活条件以可移除标签显示，并提供“清除全部”。
- 钻取后显示面包屑或返回入口，面板标题同步当前范围。

### 数据表格

- 表头粘性；数字右对齐、文本左对齐、状态居中；首要标识列可粘性。
- 明确排序方向和默认排序；筛选条件与结果数量可见。
- 超过一屏必须分页或虚拟化；当前页、总数、页容量清楚。
- 行悬停仅增强定位；选中状态必须更明显且可键盘到达。
- 长文本省略时提供完整值；时间采用统一格式；空值统一为 `—`。
- 移动/窄屏优先横向滚动与关键列固定，不把复杂分析表格强行卡片化。

## 5. 图表规则

1. 时间趋势：折线/面积线；实际与预测用实线/虚线，预测区间用透明带。
2. 类别比较与排名：排序后的水平条形图；类别多时不使用饼图。
3. 状态构成：最多 5 类时可用环图，并在中心显示总量；旁边保留数值表。
4. 行政区对比：当前南丁格尔玫瑰图改为排序条形图，除非角度编码有明确分析目的。
5. 地理数据：只有空间关系是核心问题时才使用地图。
6. 坐标轴从有意义的基线开始；不得截断造成夸大。网格线低对比，标签避免倾斜堆叠。
7. 图例置于标题下或右上，名称使用业务语言；超过 6 个系列时提供开关或分面。
8. Tooltip 同时给出时间/类别、精确值、单位和对照变化；键盘聚焦也应可读取。
9. 每张关键图提供文本摘要；关键数据提供可展开表格替代，确保无障碍和核验能力。
10. resize、空数据、加载、错误、降级状态使用统一图表壳层处理。

## 6. 推荐共享组件边界

在不引入新组件库的前提下，把现有单文件结构逐步拆为：

- `AppShell`、`TopBar`、`ViewTabs`
- `DataFreshness`、`StatusBanner`、`StateView`
- `FilterBar`、`FilterChip`、`SegmentedControl`
- `MetricStrip`、`MetricItem`
- `Panel`、`ChartPanel`、`ChartSummary`
- `DataTable`、`Pagination`
- `StatusBadge`、`EmptyState`

组件只负责呈现与交互状态；现有 API 请求、数据转换和视图语义保持不变。

## 7. 禁止项

- 营销站的 Hero、CTA、客户 Logo、超大留白和滚动叙事。
- 无业务含义的玻璃拟态、霓虹辉光、装饰渐变和 3D 图表。
- 仅鼠标可用的筛选、Tooltip 或钻取。
- 用颜色作为唯一状态编码。
- 为视觉统一而替换 Vue、ECharts、接口或业务数据结构。
