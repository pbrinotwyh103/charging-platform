# 站点负荷预测模型卡

## 用途与限制

模型预测站点未来 1、6、24、48、72 小时会话负荷及预计空闲桩，用于推荐、预警和人工决策支持。它不控制设备、不结算订单，也不应作为停止充电或扣费依据。

## 候选模型

随机森林、线性回归和梯度提升树使用同一时间切分与指标口径比较，候选模型须通过有限数值、非负会话和空闲桩边界约束，按最低 RMSE 选择并写入原子模型注册表。

## 特征与防泄漏

特征包括站点、小时、星期、节假日、天气、价格、桩数量、不可用桩和历史负荷。训练只使用预测时点之前可获得的信息。

## 指标与不确定性

报告 RMSE、MAE、R²、样本数和特征重要性。预测区间来自留出集残差分位数；漂移使用 PSI 类特征距离和滚动误差。真实指标必须如实展示。

## 回退

训练失败不覆盖当前模型；服务异常时使用最近一次有效预测并标记 `stale`，无缓存时仅分析功能降级。
