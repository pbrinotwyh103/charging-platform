# 通信协议说明

## 数据包格式

协议使用固定20字节大端序消息头和UTF-8 JSON消息体。

| 字段 | 字节数 | 说明 |
| --- | ---: | --- |
| magic | 4 | 固定为CHP1 |
| version | 2 | 当前版本1 |
| messageType | 2 | 业务消息类型 |
| requestId | 4 | 请求、响应匹配和幂等控制 |
| payloadLength | 4 | JSON消息体字节数 |
| statusCode | 4 | 成功或错误码 |

单个消息体最大4 MiB。接收端按照长度字段处理TCP分包与粘包。非法魔数、版本、长度或JSON均视为协议错误。

## 消息方向

- 请求：用户客户端或管理员客户端发送。
- 响应：服务器使用相同requestId返回。
- 推送：服务器主动向用户或管理员发送充电进度、停止结果、设备状态和告警。
