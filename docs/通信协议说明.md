# 通信协议说明

## 数据包格式

协议使用固定20字节大端序消息头和UTF-8 JSON消息体。

| 字段 | 字节数 | 说明 |
| --- | ---: | --- |
| magic | 4 | 固定为CHP1 |
| version | 2 | 当前版本1 |
| messageType | 2 | 业务消息类型 |
| requestId | 4 | 请求、响应匹配和幂等控制 |
| payloadLength | 4 | JSON消息体字节数 |
| statusCode | 4 | 成功或错误码 |

单个消息体最大4 MiB。接收端按照长度字段处理TCP分包与粘包。非法魔数、版本、长度或JSON均视为协议错误。

## 第一阶段消息

| 请求 | 响应 | 说明 |
| --- | --- | --- |
| `Ping(1)` | `Pong(2)` | 客户端每10秒发送心跳；服务端45秒无活动时关闭连接。 |
| `UserLoginRequest(1001)` | `UserLoginResponse(1002)` | 手机号免密登录，不存在时自动注册并返回基础资料。 |
| `UserProfileRequest(1010)` | `UserProfileResponse(1011)` | 仅已登录用户可读取自己的资料。 |
| `LogoutRequest(1090)` | `LogoutResponse(1091)` | 清除当前TCP连接上的身份会话。 |
| `AdminLoginRequest(5001)` | `AdminLoginResponse(5002)` | 管理员账号密码认证。 |

登录成功响应包含随机 `sessionId`、角色和账号标识。服务端以TCP连接上的会话状态作为权限依据，不接受客户端自行声明身份。普通用户调用管理员消息会返回 `Forbidden(1102)`；未登录调用受保护消息会返回 `Unauthorized(1101)`。

每个客户端请求必须使用非0 `requestId`。服务端响应沿用同一编号；同一连接上尚未完成的相同编号会返回 `DuplicateRequest(1204)`。管理员连续登录失败达到阈值后会暂时返回 `RateLimited(1205)`。

## 消息方向

- 请求：用户客户端或管理员客户端发送。
- 响应：服务器使用相同requestId返回。
- 推送：服务器主动向用户或管理员发送充电进度、停止结果、设备状态和告警。

当前课程环境使用普通TCP，已实现协议边界校验、长度限制、会话鉴权和数据库密码摘要。若系统部署到不可信网络，必须在现有协议外增加TLS，避免管理员密码和业务数据在传输中被窃听。
