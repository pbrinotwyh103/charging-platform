# 数据库模块验收说明

本模块负责SQLite初始化、迁移、完整性保护、数据访问和跨表事务。客户端仍然只通过服务端访问业务数据。

## 已实现范围

| 范围 | 实现 | 关键保证 |
| --- | --- | --- |
| 初始化与迁移 | `DatabaseManager`、`database/migrations` | 启动自动建库，按版本补充索引，启动后执行 `PRAGMA quick_check` |
| 用户与管理员 | `UserRepository`、`AdminRepository` | 手机号和账号唯一；支持资料、余额、冻结状态和登录时间维护 |
| 站点与电桩 | `StationRepository`、`PileRepository` | 支持站点汇总、电桩明细、状态条件更新和心跳维护 |
| 收藏与预约 | `FavoriteRepository`、`ReservationRepository` | 收藏幂等；同一用户和同一电桩最多一个有效预约；取消或过期后释放电桩 |
| 订单与钱包 | `OrderRepository`、`WalletRepository` | 冻结用户不能下单；充值和流水同事务；扣费、订单完成和电桩释放同事务 |
| 告警与审计 | `AlarmRepository`、`ControlRecordRepository`、`PushRecordRepository` | 保存告警处理、设备控制和推送结果 |
| 备份恢复 | `DatabaseManager::backupTo`、`restoreFrom` | 备份前检查当前库；恢复前检查备份；恢复后重新迁移并检查 |

## 自动化测试

`database_repository_tests` 覆盖以下场景：

- 结构版本、外键开关、索引和完整性检查；
- 用户资料、站点/电桩查询、收藏幂等；
- 冻结用户禁止预约、预约冲突、取消和到期释放；
- 充值入账、订单创建、进度更新、结算扣费和电桩释放；
- 余额不足时订单、钱包和电桩状态整体回滚；
- 告警、控制记录和推送记录入库；
- 在线快照备份及恢复后数据一致性。

在Ubuntu 22.04和Qt 6.2.4及以上环境中，运行 `./scripts/build.sh` 后执行 `build/bin/database_repository_tests -v1`。
