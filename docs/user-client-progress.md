# 用户端进度

## 已完成并测试

- 用户端 `ClientApi`：登录、自动注册、资料读取、退出和连接状态统一封装。
- `SnapshotStore`：按 `orderId + seq` 丢弃旧快照，并提供 10 秒过期判断。
- 主窗口登录态及“首页 / 充电 / 我的”底部导航。
- 站点距离计算与稳定排序工具（GCJ-02 数值模型可直接接入）。
- 首页区域/地址/模拟定位、站点列表和站点详情页、电桩列表页。
- 资料页昵称校验、头像 PNG/JPEG 校验与尺寸限制、充值入口。
- 头像读取后的 512×512 等比例预览。
- 充电页快照字段展示、网络断开后的非实时提示和 10 秒过期提示。
- 腾讯地图导航 URL 工具，支持环境变量/`config/app.ini` 配置 Key、驾车/步行模式和无 Key 降级。
- 主窗口统一导航及收藏操作的待联调降级提示。
- `--demo` 独立演示入口，不依赖服务端即可展示完整用户流程。
- 演示数据覆盖区域/地址查询、模拟定位、距离排序、站点卡片和电桩状态。
- 站点详情支持收藏、驾车/步行路线预览、空闲桩选择和预约确认。
- 充电页支持预约校验、开始充电、每秒快照、动态计费、80%提醒、充满自动停止、异常安全停止和结算结果。
- 用户中心支持昵称与头像前端校验、可选金额充值、余额即时刷新、充值记录和常用站点。
- 用户端专用 QtTest 已加入总工程，覆盖演示工作区、预约充电结算、充值流水和地图参数。
- 已通过 `bash scripts/build.sh` 编译验证。

## 已实现但待服务端联调

- 站点、桩详情、收藏、预约、钱包、订单和充电接口的客户端扩展入口及状态承载仍需接入真实消息处理器。
- 头像上传和昵称编辑的 API 需要服务端字段后联调；腾讯地图真实路线加载还需配置有效 Key。

## 前端展示状态

- 充值记录、完整站点详情、预约确认、充电计费、异常停止、订单结算和腾讯地图 `QWebEngineView` 已具备演示状态。
- 演示模式会明确提示本地样例数据，不把它标记为服务端联调结果。
- 联网模式保留原有消息信号和客户端 API 入口，服务端合入后再替换本地演示响应。

## 外部依赖阻塞

- 服务端尚未注册业务消息处理器，无法验证真实业务响应和充电推送。
- 需要确认钱包、收藏、活动订单、订单状态和实时推送协议字段；确认项已整理至 `docs/user-client-server-confirmation-request.md`。
