# 用户端进度

## 已完成并测试

- 用户端 `ClientApi`：登录、自动注册、资料读取、退出和连接状态统一封装。
- `SnapshotStore`：按 `orderId + seq` 丢弃旧快照，并提供 10 秒过期判断。
- 主窗口登录态及“首页 / 充电 / 我的”纵向导航。
- 站点距离计算与稳定排序工具（GCJ-02 数值模型可直接接入）。
- 首页区域/地址/模拟定位、真实站点列表查询、站点详情页和电桩列表页。
- 资料页昵称校验、头像 PNG/JPEG 校验与尺寸限制、头像压缩/Base64、资料更新失败回滚和充值入口。
- 头像读取后的 512×512 等比例预览。
- 充电页快照字段展示、网络断开后的非实时提示和 10 秒过期提示。
- 腾讯地图导航 URL 工具及 `QWebEngineView` 路线页面，支持环境变量/`config/app.ini` 配置 Key、驾车/步行模式、域名白名单和无 Key/加载失败降级。
- 需求 12 腾讯地址解析闭环：客户端页面状态、2030/2031 协议、服务端 HTTPS WebService 调用、GCJ-02 校验、3 秒超时与一次重试、Key/限流/无结果/网络错误降级。
- 历史订单服务端查询、客户端状态处理及“我的”页订单列表。
- 钱包充值请求、UUID 幂等键、重复提交保护、余额回填，以及充值流水查询、排序、金额格式化和失败重试状态。
- 站点/电桩查询错误回填、异常坐标排序保护、电桩预计可用时间和刷新入口。
- 需求 18 收藏闭环：收藏/取消收藏、请求防重、服务端幂等、失败回滚、刷新同步和收藏列表入口。
- 已通过 `bash scripts/build.sh` 编译验证；协议测试 10/10、阶段集成测试 12/12、用户端页面测试 20/20 通过。
