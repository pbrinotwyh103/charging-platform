# 第二阶段演示说明

1. 配置 `CHARGING_ANALYTICS_URL`；跨主机时同时设置一致的 `CHARGING_API_KEY`。
2. 在课程虚拟机运行 `bigdata/scripts/run_pipeline.sh --seed 20260915 --batch-id demo-1`。
3. 使用 `scripts/deploy/start_analytics.sh` 启动只读分析服务。
4. 浏览器打开大屏，演示运营、监管、租户三个专题以及加载、空数据、过期、错误状态。
5. 启动 Qt 服务端、用户端和管理端，演示预测周期切换、低拥堵排序、预警筛选和只读建议。
6. 停止 Flask，确认找桩、预约、充电、计费、管理控制仍可用，分析功能显示缓存或不可用。
7. 运行 `python3 scripts/acceptance/run.py --profile course-vm`，以生成清单为最终证据。

严禁格式化 NameNode。演示数据与真实快照必须使用不同批次和目录。
