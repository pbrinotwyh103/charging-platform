# 系统总体设计

## 运行组件

系统由用户手机客户端、管理员手机客户端、后台服务器和SQLite数据库组成。两个客户端均通过同一套TCP消息协议连接后台服务器，客户端不直接访问数据库。

## 分层原则

- 客户端：页面、控制器、网络连接、公共协议。
- 服务器：连接会话、协议解析、消息分发、业务服务、数据仓库、定时任务。
- 数据库：业务表、约束、索引、事务、迁移和备份。

## 权限原则

- 用户仅能访问本人资料、钱包、预约和订单。
- 管理员能查看运营数据并执行设备、用户和充电控制。
- 服务端根据登录会话中的角色验证每个业务请求。

## 当前阶段

第一阶段已经完成账号与连接基础能力：用户手机号登录/自动注册、管理员密码登录、默认资料、角色会话、权限拦截、心跳重连、线程池认证和SQLite自动初始化。找桩、导航、预约、充电、计费、告警和运营管理等业务仍按后续阶段实施。
