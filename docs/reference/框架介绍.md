目前项目采用“两个手机端客户端 + 一个服务端 + 一个数据库”的结构：

```
用户手机端（Qt Widgets） ─┐
                          ├─ TCP 自定义通信协议 ─→ 服务端 ─→ SQLite 数据库
管理员手机端（Qt Widgets） ─┘
```

用户端和管理员端都是独立的 Qt 程序，界面按手机端使用方式设计；两者都只负责界面展示、收集操作、向服务端发送请求和接收结果，均不直接访问数据库。

服务端是整个系统的核心，负责：

- 监听用户端、管理员端的 TCP 连接；
- 校验登录身份与角色；
- 接收并解析自定义消息协议；
- 根据消息类型分发到对应业务模块；
- 执行数据库查询、修改和事务处理；
- 向客户端返回结果或主动推送状态、告警等信息。

服务端内部已分好层：

- `network`：TCP 监听和客户端会话；
- `protocol`：数据包封装、拆包、粘包/半包处理；
- `dispatch`：按消息类型路由请求；
- `services`：登录、站点、充电桩、预约、充电、计费、订单、告警、统计、管理员等业务模块；
- `repositories`：数据库访问接口；
- `database`：SQLite 初始化和连接管理；
- `jobs`：后续用于定时推送充电状态、订单超时检查、告警扫描等任务。

数据库只由服务端访问，目前已设计用户、管理员、站点、充电桩、收藏、预约、充电订单、钱包流水、告警、设备控制记录、推送记录等 12 张表，并配置了外键和索引。

三个程序共享 `common` 公共模块，里面统一定义角色、错误码、消息类型、通信数据包和客户端连接类。通信协议已完成基础测试，封包、拆包、粘包、半包和错误包校验共 6 项测试均已通过。

现在的状态是：基础工程、通信通道、服务端分层、数据库结构和测试框架均已就位；具体业务页面与业务逻辑尚未开始填充。
