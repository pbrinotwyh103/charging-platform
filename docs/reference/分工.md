## 二、易子恒：服务端业务、通信接口与实时充电核心

负责把客户端请求转化为完整业务流程。

主要任务：

- 定义后续业务消息类型、请求字段和响应字段。
- 在消息分发器中注册各业务处理方法。
- 完成用户资料修改、头像上传、充值、充值记录查询接口。
- 完成附近站点、电桩详情、收藏接口。
- 完成预约、开始充电、主动结束和订单结算业务。
- 实现未完成订单检查。
- 实现充电状态机：

```
空闲
→ 已预约
→ 充电中
→ 停止中
→ 已完成/异常结束
→ 重新空闲
```

- 定时计算并推送电量、功率、时长、费用和充电状态。
- 检测充满、余额不足、设备故障、温度异常、电流异常和连接中断。
- 向用户端和管理员端推送告警。
- 实现管理员远程停止、重启、启用和停用。
- 实现重复请求幂等、请求超时和统一错误响应。
- 实现管理员统计查询、用户冻结、站点维护等服务接口。
- 编写服务层、协议接口和充电流程集成测试。

主要对应需求：

- 用户端第6—25项背后的服务端接口。
- 服务端第31、35—39、46—47项。
- 管理端第36、40—53项背后的查询和管理接口。

模块边界：

```
common/protocol/
server/dispatch/
server/services/
server/jobs/
tests/services/
tests/integration/
```
