# 用户端阶段验收目标与测试方法

负责人：史雨函  
适用范围：`user-client/` 及 `tests/user-client/`  
验收原则：客户端可独立验证，服务端接口可替换；未确认的服务端能力不得由客户端伪造成功结果。

## 一、阶段验收目标

### 1. 用户登录与会话

验收标准：

- [x] 手机号为空或格式错误时不能发起请求。**已完成**
- [x] 登录成功后进入“首页”。**已完成**
- [ ] 登录失败、超时、未连接时显示明确错误。**部分完成：登录失败和超时已有提示，未连接场景仍需补充统一登录失败反馈**
- [x] 重连后自动重新认证，但不打断用户当前页面。**已完成**
- [x] 退出登录后回到登录页并隐藏底部导航。**已完成**
- [x] 用户端网络请求统一通过 `ClientApi` 发起。**已完成**

测试方法：

- 输入空字符串、`123`、非数字或非 11 位手机号，确认不会发送请求。
- 使用模拟成功报文，确认登录后进入首页。
- 使用业务错误、空 payload 和超时报文，确认分别显示错误提示。
- 登录后切换到“充电”页，模拟断线和重连，确认页面不会跳回“我的”。

### 2. 个人资料与钱包

验收标准：

- [x] 正确展示昵称、手机号和余额。**已完成**
- [x] 余额以整数分为基础，并显示为两位小数。**已完成**
- [x] 昵称长度限制为 2-20 个字符。**已完成**
- [x] 头像仅允许 PNG/JPEG，尺寸不得超过 2048×2048。**已完成**
- [x] 头像可以生成预览和压缩后的 Base64 数据。**已完成**
- [x] 充值金额限制为 1-5000 元，最多两位小数。**已完成**
- [x] 充值输入框属于资料页布局，不得漂浮在窗口顶部。**已完成**
- [x] 服务端接口未提供时只显示等待联调，不修改本地余额。**已完成**

测试方法：

- 分别输入 `1`、`5000`、`5000.01`、`0`、负数和三位小数。
- 使用有效 PNG/JPEG、损坏图片和超过 2048×2048 的图片测试头像校验。
- 检查 `avatarPrepared` 信号的 MIME 类型、Base64 可解码性和图片可读取性。
- 使用 `0`、`1`、`199`、`10000` 等 `balanceCents` 测试余额显示。
- 点击充值后确认余额不会在客户端直接增加。

### 3. 首页、站点和电桩

验收标准：

- [x] 地址为空时不能进入加载状态，也不能发送查询请求。**已完成**
- [x] 使用定位或输入地址后才能搜索。**已完成**
- [x] 查询过程中显示加载状态。**已完成**
- [x] 手动地址先通过腾讯地图解析为 GCJ-02 坐标，再发起站点查询。**已完成**
- [x] 地址解析处理未登录、非法输入、Key 缺失、限流、无结果、网络失败、超时和非法坐标。**已完成**
- [x] 腾讯服务不可用或无 Key 时仍可使用模拟定位查询站点。**已完成**
- [x] 空数组显示空状态，错误或超时显示错误状态。**已完成：站点列表支持空、失败、超时和刷新状态**
- [x] 站点按距离稳定排序。**已完成**
- [x] 站点详情展示地址、价格、桩数量和收藏状态。**已完成**
- [x] 电桩列表支持加载、空数据和错误状态。**已完成：详情页支持加载、空数据、错误和刷新**

测试方法：

- 地址为空直接点击搜索，确认显示“搜索位置不能为空”。
- 输入地址后点击搜索，确认发出 `StationListRequest`。
- 输入详细地址后确认先发出 `MapGeocodeRequest`，成功响应后才发出 `StationListRequest`。
- 删除 Key、断开外网或模拟限流响应，确认页面给出对应提示且不会使用伪造坐标查询。
- 分别模拟成功、空数组、业务错误和超时响应。
- 构造相同距离的多个站点，确认原顺序保持不变。
- 打开站点详情，分别测试有桩、无桩和错误响应。
- 检查 `priceCentsPerKwh` 以及兼容字段 `price` 的显示。

### 4. 充电状态与实时快照

验收标准：

- [x] 页面能展示预约、充电、停止、对账、待付款、完成和异常等状态。**已完成：状态映射和兼容字段已接入**
- [x] 没有活动订单时显示空状态。**已完成：活动订单无数据时显示空任务提示**
- [x] 快照按 `orderId + seq` 过滤重复和乱序数据。**已完成：`SnapshotStore` 已实现**
- [x] 切换订单后序号重新计算，旧订单数据不影响新订单。**已完成：`SnapshotStore` 已实现**
- [x] 超过 10 秒未更新时显示数据过期。**已完成：存储层和充电页均有过期判断**
- [x] 断线时保留最后一次有效数据并标记为非实时。**已完成：充电页已有断线提示逻辑**
- [x] 客户端不自行生成完成或异常结束状态。**已完成：当前未在客户端推断终态**

测试方法：

- 按固定顺序发送状态快照，确认字段正确展示。
- 发送相同 `seq` 和更小 `seq`，确认报文被丢弃。
- 切换新的 `orderId`，确认序号可以从较小值重新开始。
- 超过 10 秒不发送新快照，确认出现过期提示。
- 有快照时断开连接，确认页面仍保留最后数据。
- 发送未知状态，确认显示未知状态提示而不是推断为完成。

### 5. 地图和降级体验

验收标准：

- [x] 有 Key 时可以生成驾车和步行导航 URL。**已完成：`MapNavigator` 已实现**
- [x] 无 Key 时不崩溃并显示降级提示。**已完成：导航页显示降级页面并保留手动找桩能力**
- [x] 地图不可用时仍可以手动选择站点并按距离排序。**已完成：站点搜索不依赖地图 Key**
- [x] 导航 URL 使用预期的 HTTPS 地图域名。**已完成**

测试方法：

- 设置和取消 `TENCENT_MAP_KEY` 后分别启动客户端。
- 检查驾车、步行模式及起终点参数。
- 使用空坐标和非法模式测试容错。
- 模拟 WebEngine 不可用，确认站点搜索功能仍可使用。

### 6. 常用充电站收藏

验收标准：

- [x] 收藏和取消收藏期间禁用按钮，同一站点不重复发送请求。**已完成**
- [x] 客户端先更新显示，请求失败、超时或断线时恢复原状态。**已完成**
- [x] 服务端按用户隔离收藏数据，重复设置相同目标状态保持幂等。**已完成**
- [x] 重新查询站点或刷新收藏列表后使用服务端最终状态。**已完成**
- [x] 可以从“我的—收藏站点”打开收藏列表并重新进入站点详情。**已完成**

测试方法：

- 快速连续点击收藏按钮，确认只发出一个请求且按钮在响应前不可用。
- 分别模拟业务失败、8 秒超时和断线，确认按钮及站点状态恢复。
- 收藏后刷新站点列表和收藏列表，确认状态一致；取消收藏后确认列表移除该站点。
- 使用两个用户查询收藏列表，确认数据互相隔离。
- 阶段集成测试 `favoritesAreIdempotentAndUserScoped()` 覆盖幂等、刷新、用户隔离、取消收藏和无效站点。

## 三、手工验收顺序

1. 启动服务端和客户端。
2. 测试登录失败、登录成功和自动注册。
3. 确认登录后进入首页。
4. 测试空地址搜索和正常地址搜索。
5. 测试站点详情、电桩列表和返回首页。
6. 测试“充电”页空状态、快照和断线提示。
7. 测试“我的”页资料、头像和充值输入。
8. 从“我的”进入收藏站点，测试收藏、取消、刷新、失败回滚和重新打开详情。
9. 测试断线、重连、超时和退出登录。
10. 无地图 Key 重启客户端，确认降级功能可用。
11. 保存日志、截图和模拟报文，形成阶段验收记录。
